# Pivot Business Workflow Map

Use:

- `business-os-workflow-pivot-existing-business-v2.md` as the main process
- `business-os-question-bank-v2.md` for question selection
- `business-os-evidence-rubric-v2.md` for confidence and gate discipline
- `business-os-artifact-templates-v2.md` for output shape

Primary outputs:

- Current State / Pivot Diagnosis Memo
- Asset And Capability Audit
- updated Business Definition Note
- Positioning Memo
- Offer Architecture Document
- Pricing And Unit Economics Memo
- Route-To-Market Strategy Memo
- Financial Planning Memo where needed
- Pivot Strategy Dossier

End states:

- proceed with pivot
- pivot through pilot
- defer pivot
- rethink pivot
