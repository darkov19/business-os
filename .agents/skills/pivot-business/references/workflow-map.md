# Pivot Business Workflow Map

Use:

- `business-os-workflow-pivot-existing-business.md` as the main process
- `business-os-question-bank.md` for question selection
- `business-os-evidence-rubric.md` for confidence and gate discipline
- `business-os-artifact-templates.md` for output shape

Primary outputs:

- Current State / Pivot Diagnosis Memo
- Asset And Capability Audit
- updated Business Definition Note
- Positioning Memo
- Offer Architecture Document
- Pricing And Unit Economics Memo
- Route-To-Market Strategy Memo
- Financial Planning Memo where needed
- Execution Activation Plan
- 30/60 Day Execution Plan where the pivot should move into pilot or phased execution
- Pivot Strategy Dossier

End states:

- proceed with pivot
- pivot through pilot
- defer pivot
- rethink pivot
