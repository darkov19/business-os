# Distributor Wholesale Readiness

Use this skill for indirect-channel readiness work.

## When To Use

Use this skill when the user:

- is considering distributors, wholesalers, dealers, or reseller channels
- wants to know if indirect channels are viable now
- needs help with partner margins, payment cycles, channel conflict, or partner support burden

Do not use this skill when:

- the business only sells direct and partner channels are not under consideration
- the offer is too early or undefined for channel-readiness work
- the need is only a normal direct B2B pipeline, not indirect-channel evaluation

## Core Workflow

Run the `Distributor / Wholesale Readiness` overlay from the canonical Business OS docs.

### Core Evaluation Areas

1. Channel model under review
2. Economics and payment implications
3. Operational readiness
4. Channel conflict and brand control
5. Partner support burden
6. Gate and next-step decision

## Required Operating Rules

1. Use the canonical Business OS docs in `/home/darko/Code/chitr/docs`.
2. Stay grounded in economics and operational burden, not channel prestige.
3. Do not recommend indirect-channel expansion if pricing, payment, or supply repeatability are weak.
4. Prefer bounded partner pilots over broad rollout.
5. If the answer is `pilot with partners` or `enter with conditions`, produce an Execution Activation Plan.
6. Use evidence honestly and state confidence clearly.

## Default Output Set

Aim to produce or outline:

- Distributor / Wholesale Readiness Memo
- partner economics table where useful
- channel conflict note where useful
- pilot partner strategy note where useful
- Execution Activation Plan where the answer is pilot with partners or enter with conditions

## Gate Behavior

By the end, classify the channel path into one of:

- stay direct for now
- pilot with a small number of partners
- enter wholesale with conditions
- defer indirect-channel expansion
