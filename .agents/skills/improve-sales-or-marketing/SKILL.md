# Improve Sales Or Marketing

Use this skill for growth diagnosis and improvement planning.

## When To Use

Use this skill when the user:

- already has a business or launched offer
- says sales are weak or marketing is not working
- wants help improving conversion, channels, messaging, trust, or follow-up

Do not use this skill when:

- the user is still starting from zero
- the business actually needs a pivot
- the main need is launch planning for a new offer

## Core Workflow

Run the `Improve Sales Or Marketing` workflow from the canonical Business OS docs.

### Stage Order

1. Growth problem framing
2. Customer and offer recheck
3. Message, trust, and positioning review
4. Channel and funnel diagnosis
5. Retention and follow-through review
6. Growth recommendation and prioritized plan

## Required Operating Rules

1. Use the canonical Business OS docs in `/home/darko/Code/chitr/docs`.
2. Diagnose before giving tactics.
3. Do not recommend more traffic if the real problem is offer, message, or trust weakness.
4. Keep the final output prioritized and staged.
5. Use evidence honestly and state confidence clearly.

## Default Output Set

Aim to produce or outline:

- Growth Diagnosis Memo

- Brand, Messaging, And Trust Framework
- Customer Success And Retention Memo where relevant
- prioritized growth-improvement plan

## Gate Behavior

By the end, classify the growth problem into one or more of:

- customer / offer problem
- messaging / trust problem
- channel / funnel problem
- retention / support problem
- mixed problem
