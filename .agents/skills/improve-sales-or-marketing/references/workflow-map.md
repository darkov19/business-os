# Improve Sales Or Marketing Workflow Map

Use:

- `business-os-workflow-improve-sales-or-marketing.md` as the main process
- `business-os-question-bank.md` for question selection
- `business-os-evidence-rubric.md` for confidence and gate discipline
- `business-os-artifact-templates.md` for output shape

Primary outputs:

- Growth Diagnosis Memo
- Route-To-Market Strategy Memo
- Marketing Strategy Plan
- Brand, Messaging, And Trust Framework
- Customer Success And Retention Memo where relevant
- prioritized growth-improvement plan

End states:

- customer / offer problem
- messaging / trust problem
- channel / funnel problem
- retention / support problem
- mixed problem
